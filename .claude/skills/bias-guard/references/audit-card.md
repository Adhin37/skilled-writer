# bias-guard — audit card

Opened by `revision-pass` **Pass 6**, every chapter, never skipped, never rotated. There is no
script for this pass anywhere in the toolkit, deliberately, so that no green line from a linter
can ever be mistaken for a bias pass.

- [ ] No group treated as uniformly anything by the narration
- [ ] Every named woman in the chapter wants something that is not the MC
- [ ] No character introduced by a body inventory
- [ ] No physical trait or accent signalling moral quality
- [ ] Nobody is a reward
- [ ] Any prejudice on the page belongs to a character and costs someone something

**The distributional half**, which no single line reveals — ask it of the chapter as a whole:

- [ ] If the thin, silent, or corrected roles in this chapter were listed, would they sort by
      gender, class, nation or body? `sw cast` prints the competence distribution; the sorting is
      the question it cannot answer
- [ ] Did the chapter's authority, expertise and last word land where genre convention would have
      put them by default

If Pass 6 found anything, **say so in the report**, always. The user needs to know the default was
reaching for it. If a box fails, open `SKILL.md` — §The line, then the section for the axis.
