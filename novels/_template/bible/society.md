# Society

Built and maintained by `social-fabric`. The layer between the world's central rule
(`power-system.md` / `canon.md`) and the daily life a scene can be set in.

Same test as `world.md`: an entry belongs here only if a scene could **contradict** it, it
**constrains** a character, or it will be **referenced more than once**. Target 600–1,000 words
at init. Grow it only when the story enters a layer it has not shown.

## The six questions

| # | question | answer (1–2 sentences) |
|---|---|---|
| 1 | Labour — what do most people do all day, and who does the work nobody wants? | |
| 2 | Money — what is wealth made of, and how does an ordinary person fall out of it? | |
| 3 | Violence — who may legitimately hurt whom, and what happens when someone else does? | |
| 4 | Knowledge — who may learn, what is written down, how fast does news travel? | |
| 5 | Belief — what do people think the world is, and what do they do on the days that matter? | |
| 6 | Mobility — can a person change their position, and by which route? | |

## Propagation of the central rule

One table per hard rule from `power-system.md` / `canon.md`. See `social-fabric` §2.

| Household — what an ordinary family does differently because of it | |
